# Supported R1 recommendation facts and controlled interpretations

Authority: owner policy in [#14](https://github.com/jsnwilmot/PrintGuard3D/issues/14#issuecomment-6507323728), implementation [#23](https://github.com/jsnwilmot/PrintGuard3D/issues/23). Policy version 1.0.0, 2026-10-29. This is an application policy, not a FlashForge correction or servicing approval.

| Fact / interpretation | Exact applicability | Classification and action |
| --- | --- | --- |
| Creator 5 400/500/1,500/3,000-hour article figures and 1,000-print-hour guide wiping | Accepted immutable C5 definitions only; precise sources/materials/versions remain in those definitions | Manufacturer Documented **numeric fact** only when the entire existing exact-definition verifier passes. Whole-printer operating-hour counting is a separately disclosed provisional PrintGuard proxy, not exact per-extruder/component time. Anchors and existing intervals are unchanged. |
| Pro 1,000-print-hour shaft wiping | Pro's own full guide, not the C5 article catalogue | Manufacturer Documented narrow numeric fact. Pro v1.0.0 still has one template; no cold-pull or other series recurrence is added. |
| Explicit published usage-band selection | C5 accepted usage templates; owner-selected option only | Manufacturer Documented published option, not proof the owner's actual usage belongs to that band. Base templates remain condition/reference-only until explicit selection. Ambiguous metrics/boundaries remain disclosed. |
| Fan exactly 5 hours/day -> 6 months; exactly 10 -> 3 months | Exact C5 FDM/FFF only | Optional PrintGuard Suggested **inspection/review reminder**, never an instruction to clean or replace. The [source](https://wiki.flashforge.com/en/creator-series/creator-5-series/maintenance/cooling-fan-dust-cleaning) omits both boundary values. Fan source says working hours, whereas the optional app calculation uses printing hours: mismatch unresolved. |
| X/Y exactly 5 -> 1 month | Exact C5 FDM/FFF only | Optional PrintGuard Suggested review reminder. [X source](https://wiki.flashforge.com/en/creator-series/creator-5-series/maintenance/clean-and-lubricate-the-x-axis-linear-shaft) and [Y source](https://wiki.flashforge.com/en/creator-series/creator-5-series/maintenance/clean-and-lubricate-the-y-axis-linear-guide-rail) overlap at 5. Reminder links the representative X reference; it does not attach a lubrication procedure or merge active X/Y tasks. |
| Z exactly 5 -> 3 months | Exact C5 FDM/FFF only | Optional PrintGuard Suggested review reminder; [source ranges overlap](https://wiki.flashforge.com/en/creator-series/creator-5-series/maintenance/z-axis-lead-screw-cleaning-and-lubrication). No automatic lead-screw/bearing lubrication. |
| Any other value, including just below/above a boundary | All groups | No PrintGuard boundary suggestion; no rounding, interpolation or automatic schedule change. Owner may use existing User Defined task controls separately. |
| Owner-custom interval for one of the above reviews | Same exact C5 model | User Defined; initial decision and original interval retained separately. Existing servicing rules are never edited by acceptance. Reject/defer stores nothing. |
| Optional 30-calendar-day actual printing average | Owner-declared printing counter with 31 valid distinct date endpoints through today | PrintGuard calculation, not manufacturer method. Every day must have a valid endpoint. Conflicting same-day totals, gaps, decreasing/invalid counters, >24-hour daily increase or end totals differing from the printer make it unavailable. Identical duplicate endpoints do not add coverage. No idle-day zero inference, lifetime average or sparse extrapolation. Date-only arithmetic avoids DST-hour assumptions. |
| Owner-reported exact daily printing value | Owner assertion, no manufacturer averaging evidence | Explicitly unverified manual basis; retained in decision metadata. The fan working/printing mismatch still applies. |
| Pro HEPA13/carbon hardware | Exact Pro only | Hardware fact supported; **clean/replace, discoloration scope, parts and cadence remain unresolved**. A separate owner-defined condition/visual inspection may be tracked with no default recurrence. The [ambiguous article](https://wiki.flashforge.com/en/creator-series/creator-5-series/maintenance/filter-cartridge-replacement) is a reference, not a new requirement. |
| Stock C5 or optional mechanical enclosure filtration | No documented Pro-equivalent configuration | No default filter reminder, cleaning or replacement cadence. No automatic Pro equivalence. |
| Video-only repair/setup/safety procedures, PCB firmware prerequisites, expanded manufacturer catalogue | Outside supported automatic R1 scope | No recurring physical action inferred. Actual manufacturer servicing instructions and qualified help remain necessary. Broader guided procedures/catalogue are future work, not promised R1 coverage. |
