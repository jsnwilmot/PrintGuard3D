## Confirmed application description for review

PrintGuard 3D is an independent maintenance tracker. The reviewed application saves workshop records in IndexedDB in the current browser profile. Records can include printer identifiers, readings, rules, maintenance history, costs, inventory, repairs, photos, notes, preferences, source decisions and prospective overdue observations. It has no app account, workshop upload, automatic synchronization or analytics integration in reviewed source. This statement does not describe all live host/provider behavior.

Local records have no automatic expiry. Site clearing, storage eviction/private browsing limits or device loss can remove them. Download full backups regularly and before upgrades/imports. Keep protected copies and test restoration in an isolated profile. Files are not encrypted by PrintGuard and can contain personal text/images/decisions. Reports are not full backups; older app readers can reject newer optional fields. Without a usable backup, recovery may be impossible. Printer deletion/replacement does not remove retained observations, and browser clearing does not erase downloaded, mail, print or other external copies.

The host serves app files; service-worker caching supports offline use but can still request site files/navigation. Notifications require permission and can expose record details on the device; disable them in Settings/browser permissions. User-selected imports/images are processed locally; downloads and print/calendar outputs use the user's chosen clients/destinations. External documentation sites receive their own requests when followed. Feedback opens a user-controlled email draft, not an automatic send. Share only information needed for the inquiry.
